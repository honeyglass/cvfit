# IT Project Manager Infrastructure & Cloud Transformation at DaVita, Hamburg

A summary in our own words of a real posting, read on 2026-11-16 on the job board of the German
Federal Employment Agency: [reference 20250-1784115263-S](https://www.arbeitsagentur.de/jobsuche/jobdetail/20250-1784115263-S).
Full time, permanent, Hamburg with some remote work, start 2026-08-01, posted in German.

**Tasks**

- Own infrastructure projects from start to finish: cloud migration, data center, hybrid IT
- Plan migrations to Azure, AWS or Google Cloud and carry them out with teams and vendors
- Steer budgets, schedules and resources, and keep everyone involved informed
- Introduce automation: infrastructure as code (Terraform, Ansible), workflows (such as n8n)
- Spot risks early and plan countermeasures

**Must have**

- A degree in computer science or business informatics, or a similar qualification with work
  experience
- Several years of IT project management in infrastructure, data center or cloud projects
- Knowledge of cloud, virtualization, network and security, backup and disaster recovery,
  Microsoft infrastructure, infrastructure as code
- Fluent German, very good English, living in the Hamburg area

**Nice to have**

- Certificates such as PRINCE2, PMP, ITIL, Scrum, Azure, AWS or GCP
