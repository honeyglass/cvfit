# IT-Projektmanager Infrastruktur & Cloud Transformation bei DaVita, Hamburg

Eine Zusammenfassung in eigenen Worten einer echten Anzeige, gelesen am 16.11.2026 in der
Jobbörse der Bundesagentur für Arbeit: [Referenz 20250-1784115263-S](https://www.arbeitsagentur.de/jobsuche/jobdetail/20250-1784115263-S).
Vollzeit, unbefristet, Hamburg mit Remote-Anteil, Start 01.08.2026, Anzeige auf Deutsch.

**Aufgaben**

- Infrastrukturprojekte von Anfang bis Ende verantworten: Cloud-Migration, Rechenzentrum,
  hybride IT
- Migrationen nach Azure, AWS oder Google Cloud planen und mit Teams und Dienstleistern umsetzen
- Budgets, Zeitpläne und Ressourcen steuern, alle Beteiligten informieren
- Automatisierung einführen: Infrastructure as Code (Terraform, Ansible), Workflows (z. B. n8n)
- Risiken früh erkennen und Gegenmaßnahmen entwickeln

**Voraussetzungen**

- Studium (Wirtschafts-)Informatik oder vergleichbare Qualifikation mit Berufserfahrung
- Mehrere Jahre IT-Projektleitung in Infrastruktur-, Rechenzentrums- oder Cloud-Projekten
- Wissen in Cloud, Virtualisierung, Netzwerk und Security, Backup und Disaster Recovery,
  Microsoft-Infrastruktur, Infrastructure as Code
- Fließend Deutsch, sehr gutes Englisch, Wohnort im Raum Hamburg

**Wünschenswert**

- Zertifikate wie PRINCE2, PMP, ITIL, Scrum, Azure, AWS oder GCP
