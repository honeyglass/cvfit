# docs/

The longer explanations behind the README, one topic per page.

The README gives the overview and links here for the details.

## Contents

- `examples.md`: the three examples with their pages, postings and the agent's reports.
- `by-hand.md`: how to work with oriko by hand, without an agent.
- `sample-data.md`: how to try oriko on the sample data in `examples/`.
- `cli.md`: the commands, the Agent DX rules oriko follows, and how a refusal reads.
- `terminal-preview.md`: what each mark of the terminal preview means.
- `good-to-know.md`: short answers, such as how to start without a CV and what to check before
  you send.
- `baselines.md`: for maintainers, how to renew the Google PDFs of the examples.

## Connections

- **Uses:** [examples/](../examples/README.md) for the showcase files the pages show, and
  [tools/](../tools/README.md), whose baselines `baselines.md` explains.
- **Used by:** the [README](../README.md) links every page, under Docs and under Development.
  Folder READMEs link the page on their topic, such as [cli/](../cli/README.md) and
  [tools/](../tools/README.md).
