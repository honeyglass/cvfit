# classic/

The classic look: the CV as a Word file in two columns, with your photo.

It turns the page plan from `core/` into a .docx that Google Docs and LibreOffice set the same
way, so the PDF from either matches what oriko planned. Jobs stand on the left, skills and
languages on the right, and the photo sits round at the top.

The photo lives here too, since only this look shows it: `oriko photo set` takes any PNG or JPEG
and stores it as the square picture the CV uses.
